Tokens: {K:<key name>} (Key<Name>.png, e.g. {K:F} {K:Esc}; names without an image get KeyCap.png + text), {K:ARROWS} {K:ARROWSV} {K:ARROWSH}, {M:L} {M:R} {M:WHEEL}.
<keyboard|pad> in UI text picks one side by the last used input device (InputManager::GetLastDevice).
