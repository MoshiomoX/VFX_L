Item icons (Assets/Texture/UI/Icons)
====================================

All files are 136x136 PNG: the 34x34 originals scaled up 4x with nearest
neighbour, so they stay crisp under the sprite renderer's linear filter.

From "496 pixel art icons for medieval/fantasy RPG" by Henrique Lazarini (7Soul1)
  https://opengameart.org/content/496-pixel-art-icons-for-medievalfantasy-rpg
  License: CC0 (public domain). No attribution required.
