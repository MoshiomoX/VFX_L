Item icons (Assets/Texture/UI/Icons)
====================================

All files are 136x136 PNG, white silhouettes on transparency (straight alpha).
They are generated by Tools/BuildGameIcons.ps1 (the item -> icon table is in
that script). Since 2026-09-28; the earlier 7Soul pixel icons are in git history.
