# 雑魚（GPU 群体）：外观・碎裂・种类

> 2026-11-13 从 CLAUDE.md 原样搬出（文字未改）。之后这一块的新记录直接追加到这里。

- **雑魚外观**：`SwarmSystem::BuildEnemyModel` 候选表（Kenney Blocky L 僵尸 → KayKit Minion → 胶囊）。方块人是刚体部件，用 `Model::LoadOptions` 烘姿势，`BuildEnemyPartAnim` 做 idle / walk / attack 的部件动画表，`SwarmEnemyVS` 按敌人状态选帧。**脚底对齐（2026-10-03，用户指出 Boss 的脚陷在地里）**：网格仍用走路 0.25 帧烘，但脚底和高度（`targetHeight` 1.6m）改按 **idle 第 0 帧**的包围盒量。以前按走路 0.25 帧（两腿张得最开、最低点最高）对齐，idle / 攻击 / 走路的大部分帧脚都在地下 0.29m（精英 0.63m、Boss 0.86m，普通雑魚被草挡住没发现）；现在站着时脚正好在地面上（idle 每帧误差 0、攻击 ≤1.2cm），走路时腿像钟摆摆起、最多离地 0.25m（Kenney 原本的动法），站姿头顶 +0.7（= 血条 `offset` 1.0 的注释前提）。另外 `Model.cpp` 的 `ApplyNodePose` 会跳过「和前后两个键都差 120 度以上、前后两个键彼此接近」的旋转键：assimp 从 FBX 欧拉曲线转换时在过零处插的键有的翻了近 180 度（`attack-melee-right` 的 torso / head t=12.523、左臂 13.524、右腿 14.502），以前攻击正中间那帧上半身转到地下、整个身体沉下去约 0.8m。
- **死んだ敵的碎裂飞散（2026-10-02，用户在 3 个方案里选的「方块碎裂飞散」）**：以前 GPU 雑魚死了直接消失。现在 `SwarmCorpseTrackCS`（每帧，Flush 里液面追踪之后）对每个敌人槽比较「上一帧活着（`m_EnemyPrevAliveBuffer`）、现在 DEAD」，把死时的位置 / yaw / 种类 / 飞散方向（离开玩家）写进尸体环（`m_CorpseBuffer`，`Swarm::kMaxCorpses` = 512，`Swarm::Corpse` 48B，`cause` 字段留给以后按死因变化；RAW `m_CorpseHead` 是累计数），并在脚下放一个 0 伤害的范围 `MobDeath`（AreaData + VFXData，Kenney smoke 烟团 + dirt 土块；`corpse.deathArea` 由 `MobSpawner::Init` 按名字查，F4 里没有）。不在 HitCS 里做：它的 8 个 UAV 已满，而且这样所有死法（弹 / 范围 / 自爆）走同一处。`KillAll` 会清 prevAlive，清场不会全体一起碎。`SwarmCorpseListCS` 把还在碎裂中的（age < life）按外观分进 3 个 append 列表（雑魚+精英+Boss / 自爆兵 / 幽灵）→ CopyStructureCount 进每个 submesh 的间接参数（`m_CorpseDrawArgs`，和 `m_EnemyDrawArgs` 一起由 `CreateEnemyDrawArgs` 建）。绘制 `SwarmSystem::RenderCorpses`（雑魚之后、经验球之前）：同一网格、同一 PS、同样的贴图切换，只把 VS 换成 `SwarmCorpseVS`（Material::Bind 会连 VS 一起换，所以绑完再换）。VS 按 (seed, 部件, 年龄) 的公式：离开玩家方向 × fling + 部件自己朝外 + 随机横向 + 向上 up 的初速，重力 gravity 抛物线到部件支点落回静止高度，弹一次（bounce，横向速度减半），之后不动；绕随机轴自转（落地后 1/3）；死的瞬间顶点色 × flash（bloom）在 flashTime 内恢复；从 life × shrinkStart 开始缩到 0。支点 = `BuildEnemyPartAnim` 里烘焙姿势的节点原点（`m_PartPivots`，颈 / 肩 / 胯）。精英 / Boss 按种类倍率放大并扔得稍远，幽灵的碎片半透明。参数 `SwarmSystem::corpse`（life 0.9 / fling 3.5 / up 4.5 / gravity 18 / spin 9 / bounce 0.35 / flash 3 / flashTime 0.08 / shrinkStart 0.55），Swarm (GPU) 面板「Death Shatter」。自测 `death`（见 docs/autotests.md）。用户 10-02 实机看过。
- **雑魚血条**：`SwarmEnemyHpBarVS/PS`，满格值在 `m_EnemyMaxHpBuffer`，由生成 CS 和回收 CS 写入。
- **经验球外观**：自发光青蓝宝石（`PrimitiveBuilder::CreateBipyramid` 四角双角锥）。`SwarmOrbVS` 做浮动 / 自转 / 脉动（每槽相位不同），被吸引时长轴倒向玩家、沿速度拉伸（保体积）、变色变亮；`SwarmOrbPS` = emissive + 面的明暗 + 菲涅尔边 + 太阳高光 + 雾（b0 LightBuffer，b1 `OrbShadeCB`）。参数 `SwarmSystem::orbLook`，Swarm (GPU) 面板「Exp Orbs」。
  - `Orb.velocity` 以前一直是 0，现在由 `SwarmOrbMoveCS` 写本步的水平吸引速度（只给外观用，布局没变）。
  - 尾迹：`SwarmOrbEmitCS`（`SwarmEmitCS` + `SWARM_EMIT_ORBS`，b3 = `OrbEmitCB`）让吸引速度 > `trailMinSpeed` 的球按 `VFXId::ExpOrbTrail`（`ExpOrbTrail.json`）喷粒子，排在弹、范围之后发射（粒子池不够时先少的是它）。
  - 拾取：`FeedbackVFXSystem::OnExpPicked`，GPU 经验差分 > 0 时在玩家身上播 `ExpPickup.json`，限频 0.15 秒。
- **雑魚种类 / 自爆兵**：种类在并行 buffer `m_EnemyExtraBuffer`（`Swarm::EnemyExtra` = kind + fuse，8B）。生成请求用 `Enemy::animIndex` 带种类，SpawnEnemyCS / RecycleCS 取出后清 0（`SpawnEnemy` / `RecycleEnemy` 的 `kind` 参数）。种类：0 雑魚 / 1 自爆兵 / 2 精英 / 3 Boss（2026-09-29）/ 4 幽霊（2026-09-30，见「关卡流程」）。绘制列表 `kEnemyKinds` = 3（`kDrawListMob / Bomber / Ghost`，精英 / Boss 走雑魚列表）。
  - **精英 / Boss**：和雑魚同网格同贴图、走 mobList（`kEnemyKinds` = 描画列表数，仍是 2），VS 按种类以脚底为基点放大并染色（精英暗红、Boss 紫）。参数追加在 `BomberCB` 末尾（`eliteScale/DamageMul/ExpMul`、`bossScale/DamageMul/ExpMul`，现 64B；这个 CB 不在「默认不改」名单里）。`SwarmKindScale / SwarmKindCapsule / SwarmKindDamageMul / SwarmKindExpMul`（SwarmCommon.hlsli）让 HitCS（先按最大体格粗筛再读种类）、AreaDamageCS、ContactCS、AICS（停在玩家前的距离）、HP 条 VS 用放大后的胶囊；经验球价值乘倍率；Boss 不受击硬直；RecycleCS 不回收精英 / Boss。
  - **Boss 回读**：`SwarmEnemyCompactCS` 顺带把 Boss 的数量 / HP / 最大 HP / 位置写进 32B 的 `m_BossInfoBuffer`（每帧清零），3 张 staging 轮转回读（`SwarmSystem::GetBossInfo`，2〜3 帧延迟，没动 `SwarmCounters`）。
  - 自爆兵（`kEnemyKindBomber`）不近战：在接触 CS（第 6 段）里碰到玩家就点燃，点燃后 AI 让它原地停下；`fuseTime` 秒后爆炸，玩家在 `blastRadius` 内受 `blastDamage`（只伤玩家），自己变 DEAD（不算击杀、不掉经验），原地放 AreaData `BomberBlast`（伤害 0，只为 GPU 播 `Explosion.json`）。引信中被打死 = 正常击杀，不爆炸。
  - 参数 `Swarm::BomberCB`（新 cbuffer：ContactCS b3、雑魚 VS b5，HLSL 里 `#define SWARM_BOMBER_CB_REG` 才声明），`SwarmSystem::GetBomberParams`，`blastArea` 由 `MobSpawner::Init` 按名字查。
  - 外观：18 个 Kenney 方块人是同一网格同一 UV，自爆兵 = 雑魚网格换贴图 texture-g（红色机器人，`Res::Tex::Kenney_BlockyRobotAlbedo`）。CompactCS 按种类出存活列表（`m_KindList*`，全体 `aliveList` 只给血条用），每种各画一次、画自爆兵前换 PS t0。点燃后 VS 越闪越快（红色高亮）并以脚底为基点鼓到 1+swell 倍。
  - 刷怪：`MobSpawner` 对每个新刷/转送按 Bomber Ratio（默认 0.15）抽选；Enemies 面板「Bomber (GPU)」段调参，「Spawn 5 Bombers Nearby」在玩家 8〜12m 处出 5 个。
  - 同一时间连着几个爆炸，玩家的无敌帧只让第一次掉血（GPU 的累计伤害照算）。
  - **分裂怪（`kEnemyKindSplitter` = 5 / 分裂体 `kEnemyKindSplitling` = 6，2026-10-03）**：用户在「远程 / 冲锋 / 分裂 / 盾兵」里先选了分裂怪；登场方式选「两者结合」= 每关有自己的主力新敌人 + 关内按时间增加。HP 30（雑魚 2 倍）/ 3.2 m/s / 体型 1.15 / 经验 ×1.5；死后在原地周围 0.7m 出 3 只分裂体（HP 6 / 速度 = 雑魚 ×1.3 / 体型 0.6 / 接触 ×0.5 / 经验 ×0.3，不再分裂）。外观 = Kenney Blocky D（黄色假人，`Res::Tex::Kenney_BlockyDummyAlbedo`），分裂体同贴图缩小。**分裂事件**：`SwarmCorpseTrackCS` 发现分裂怪死亡（`prevAlive` → DEAD，和碎裂同一处，所以弹 / 范围 / 任何死法都算，`KillAll` 不算）就写进分裂环（`m_SplitBuffer`，u5，开头 16B 永久累加总数 + 16B × `Swarm::kMaxSplitEvents` 128，`Swarm::SplitEvent` = 位置 + 种类），和誘発環一样 3 张 staging 回读（`SwarmSystem::ConsumeSplitEvents`，2〜3 帧延迟）；碎裂关掉时也照写。`MobSpawner::SpawnSplitlings` 每帧取出、在死亡点周围 120° 间隔放（落点是阻挡格就放在死亡点），不受同时上限限制，播 `enemy_split`（黏液声）。**比例**：`StageDef::splitter`（`EnemyMix`：start / ratioStart / ratioEnd / rampEnd）→ `MobSpawner::splitter*`，第 1 面（主力）60 秒起 10% → 480 秒 25%，第 2 / 3 面 120 秒起 5% → 12%；每次刷新 / 转送先按自爆兵比例、再按分裂怪比例抽。种类参数追加在 `BomberCB` 末尾（80 → 112B：`splitterScale/DamageMul/ExpMul`、`splitlingScale/DamageMul/ExpMul`），`SwarmKindScale / DamageMul / ExpMul` 认新种类。绘制列表 `kEnemyKinds` 3 → 4（`kDrawListSplitter` = 2，幽灵挪到 3 仍最后画），CompactCS `splitterList`（u5）、CorpseListCS `splitterCorpses`（u3），`SwarmSystem::ListAlbedo` 按列表换贴图（没有专用贴图的列表会换回雑魚贴图）。顺带修了 `SwarmRecycleCS` 的「`kind >= ELITE` 不转送」（新种类编号在幽灵后面，会被误判成永不转送），改成只排除精英 / Boss / 幽灵。Enemies 面板「Splitter (GPU)」全部参数 + 「Spawn 5 Splitters Nearby」。自测 `split`（见 docs/autotests.md）实测：每只分裂怪死亡 = 1 个事件 = 3 只分裂体（6 事件 → 18 只），计时 470 秒时自然刷怪里分裂怪占 0.263（预期 0.246）；截图里分裂体明显小一号。
  - **突撃兵（`kEnemyKindCharger` = 8）/ 盾兵（`kEnemyKindShield` = 9）/ 冻结（2026-10-08）**：用户问「还要加什么」时我推荐了远程小怪，用户选了我顺带列的**冲锋兵 + 盾兵 + 冰魔法**（语音识别成「冲刺顿别人还有兵」），三项设计选推荐（冲锋兵那题没答，按推荐做）。
    - **突撃兵**：外观 Kenney Blocky R（黑忍者，`Kenney_BlockyNinjaAlbedo`）。HP 20 / 3.8 m/s / 体型 1 / 接触 ×1 / 经验 ×1.5。同高度（|dy| < 1）、玩家在 `chargerMinDist〜MaxDist`（6〜12m）、到玩家的直线全是可走格且不过崖（AICS `ChargeLineClear`）、自己 moveSpeed > 0（训练场的「不动」不冲）时：停下溜め `chargerWindup` 0.8 秒（方向在这一刻锁定 = `Enemy.yaw`，地面画红橙色带 + 「>」箭羽，身体红闪越来越快）→ 以 `chargerDashSpeed` 14 m/s 直冲 `chargerDashDist` 14m（穿过玩家、撞墙 / 崖速度掉一半以上就提前结束；冲刺时硬阻挡的前瞻只看 2 步，否则 5m 外的墙就让它停）→ 原地喘 `chargerRecover` 1.2 秒 → 普通追 `chargerCooldown` 4 秒。冲刺中撞到 = 接触伤害 × `chargerDashDamageMul` 1.8、记进爆炸那一路的击退（= 爆炸级击退 + 上抛）。溜め / 冲刺 / 喘气中不受击硬直（HitCS / AreaDamageCS 的 `noFlinch`，否则 MoveCS 每发都会让冲刺停一下）。**状态存在 `EnemyExtra.fuse`**（< 0 冷却、0 追、> 0 = 溜め开始后的秒，`SwarmChargerPhase` 分段），AICS 是它唯一的写入者（`enemyExtra` 从 t5 SRV 改成 u2 UAV）；冻住时溜め / 冲刺作废。
    - **盾兵**：外观 Kenney Blocky J（藏青警察，`Kenney_BlockyPoliceAlbedo`）+ 身前一面**塔盾**（特效模型 `Assets/VFX/Mesh/dun01.FBX`，`SwarmShieldVS` + 雑魚的 PS + 默认白贴图 × `shieldLook.tint` 钢青灰，跟朝向、走路上下晃，写敌方模板 = 红色阵营描边绕到盾上；盾兵一览的 indirect 参数按 submesh 另建 `m_ShieldDrawArgs`）。HP 30 / 3.0 m/s / 体型 1.1 / 接触 ×1.2 / 经验 ×2。**装甲**（用户选的「每次伤害减固定值」）：`SwarmArmorDamage` = max(伤害 − `shieldArmor` 5, 伤害 × `shieldMinFrac` 0.2)，弹每发一次、范围每个 tick 各算一次（3 个毒沼 = 3 次小伤害）。实测：毒 3 → 0.6、石弾 22 → 17，5 秒内盾兵 / 雑魚掉血比 毒 0.26、石弾 0.77。
    - **比例**（沿用「每关主力 + 关内按时间增加」）：`StageDef::charger / shield`（`EnemyMix`）→ `MobSpawner::chargerMix / shieldMix`（`KindRamp::At`）。第 2 面主力突撃兵、第 3 面主力盾兵（60 秒起 8% → 480 秒 18%），其他面 150 / 180 秒起 3% → 540 秒 8%。`Request` 的分段顺序 自爆兵 → 分裂怪 → 重装兵 → 突撃兵 → 盾兵 → 雑魚。**第 1 面 9 分钟时特殊兵合计约 78%**（自爆 15 + 分裂 25 + 重装 22 + 突撃 8 + 盾 8），没跑 curve 看整体难度。
    - **GPU 侧**：`BomberCB` 144 → 224B（charger 12 个、shield 5 个、freeze 3 个参数）；绘制列表 `kEnemyKinds` 5 → 7（`kDrawListCharger` 4 / `kDrawListShield` 5 / 幽灵 6 仍最后）。**CompactCS 的 UAV 已满 8 本**（FL 11.0 上限），突撃兵 / 盾兵的一览由新 CS `SwarmEnemyKindListCS` 在 CompactCS 之后另做，CompactCS 的 mobList 排除这两种；CorpseListCS 加 `chargerCorpses`（u5）/ `shieldCorpses`（u6）。新代码都在 `Swarm/SwarmSystemKinds.cpp`（SwarmSystem.cpp 已 3200 行）；Enemies 面板的段在 `Enemy/MobSpawnerKinds.cpp`（「Charger (GPU)」「Shield Bearer (GPU)」「Freeze (GPU)」+ Spawn 5 按钮）。训练场「群れの種類」加了突撃兵 / 盾兵（混合 = 雑魚 35 : 自爆 15 : 分裂 15 : 重装 10 : 突撃 10 : 盾 10 : 幽灵 5）。
