- **設置枠の形と効果（2026-10-27，用户试玩后：「放置格只有 3x3 太无聊」「纯 3x3 太强」「让放置格影响放在上面的魔法，范围强化 / 单体强化之类」→ 按我的方案做）**：枠 9 种（`Items/Frames.h` + `Frame3x3.h`）。**普通拡張枠**：3x3（开局装备；`weight` 0.25 = 卡里稀有、`priceMul` 2）、2x3、L 字 4、十字 5、一列 1x4。**効果の枠**（小，3〜4 格，说明卡种类写「効果の枠」）：範囲の枠 2x2 = 命中判定 / 范围 ×1.2；一撃の枠 1x3 = 弹的直击威力 ×1.25（`AreaDamage` 不动，范围魔法里只有アークボルト（`chainOnly`）吃）；速射の枠 L 3 格 = 发动间隔 ×0.85；吸血の枠 T 4 格 = 吸血 +3%。**规则**：魔法只要有一格压在效果枠上就吃这个效果，同种枠不叠加（`BackpackLogic::GetEffectFrames`，按枠 ID 去重）；聚合（`BackpackAggregateSystem`）和说明卡（`ItemInfo::DescribePlaced`）都在**符文之后、魔法威力之前**套 `FrameItemDef::spellModifiers / areaModifiers`，说明卡的「強化:」也列出枠名。`FrameItemDef` 多了 `spellModifiers / areaModifiers / HasEffect() / weight / priceMul`。**卡池**：放置格每种权重 = `LevelUpSystem::frameWeight` 0.2 × `weight`（合计约 1.5 张魔法）；商店 [4] 也按 `weight` 抽、价格 = `priceFrame` × `priceMul`。**画面**：`BackpackUI::Draw` 把效果枠的格子铺枠色（α 0.2）+ 枠色边线，重心那格画淡图标（魔法在它上面画）。图标 game-icons `lorc/expanded-rays / archery-target / sands-of-time / bleeding-heart`（README 已署名；普通枠用 3x3 的格子图），`Tools/BuildGameIcons.ps1` 的表也加了。ItemID 的空位 `Frame2x2 / FrameLine3` 改名掉了。`lifesteal` 自测结尾把 4 种效果枠都铺上、开背包拍 `lifesteal look bag`。**没做**：枠效果的平衡（数值是初值）、手柄 / 鼠标拖效果枠的实机手感。

当初谈的方案（原文）：不做摇杆模拟鼠标光标（多格形状对不准），做格子吸附的拿起 / 放下：
- 左摇杆 / 十字键 = 光标在 9x9 上一格一格跳（按住连续）；A = 拿起 / 放下；B = 手里有物品时取消（回原位），没有时关背包；LB / RB = 旋转；X = 把光标下的物品送回魔法书。
- 拿在手里：半透明形状跟光标按格移动，放不下变红；影响格和高级魔法前置连线沿用现在拖动时的画法（`BackpackUI::DrawTriggerSources` 等）。逻辑层直接用 `BackpackLogic` 的 CanPlace / Place / Remove。
- 魔法书木箱是物理堆叠、没有格子：手柄不直接抓堆里的东西。Y（或 RT）在背包 / 魔法书之间切焦点；焦点在魔法书时左右键按顺序切换物品，选中的高亮浮起，A 拿起后焦点回到背包格子。物理堆叠只当外观，鼠标照旧能抓。
- 说明卡：光标停在物品上约 0.3 秒自动出，位置固定在格子旁。
- 最后一次输入来自手柄 → 显示格子光标、藏鼠标指针；鼠标一动切回去，按键提示跟着换。
- 顺序：先做背包格子（主体），能用了再接魔法书。注意现有手柄键位：Start 背包、Back 暂停、A 跳、B 交互、X 滑铲 / 选卡刷新、Y 魔力解放（背包打开时 gameplay 停，可以复用这些键）。
