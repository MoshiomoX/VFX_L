- **C+ 沙面状态场** 新 `World/SandField.h/.cpp`（照 `GrassFireField` 的结构）：
  - 贴图：**状态** `R32G32B32A32_FLOAT` 512² 双缓冲（x = 温度、**y = 干燥度 = 1 − 湿度**、z = 热到出陽炎的印 (温度 > `hazeHeat` 且干燥度 > 0.3)、w 不用）；**沙痕** `R32_FLOAT` 512² 双缓冲（深度，负 = 凹）。用 R32 的理由同草的延烧（每帧的变化量小于半精度 1 ulp 会卡住）；沙痕单独一张是因为敌人踩印要 RMW（读改写），而 typed UAV load 只保证 R32_FLOAT / UINT / SINT，float4 不保证。

  - **形状 `TreeBuilder`**：阔叶树 = 干（高 0.26〜0.34H）+ 主干延长 + 5〜7 根大枝（金角错开、仰角 18〜54°）+ 每根 4〜6 根小枝，叶子贴在小枝（120 枚/m）和大枝末端（80 枚/m）；枯木同骨架不贴叶；茂み = 6〜9 根从根部斜出的茎 + 小枝、68 枚/m。管子按层 8 / 6 / 4 / 3 边、平行移动坐标系、尖端封口。每个顶点带风用权重：`mainW` = (h/H)^1.6（茂み ^1.2）、`branchW` = 挂点的权重 + 柔度 × s^1.5（子枝继承父枝的相位，关节不裂开）。叶 = 一张四边形，PS 里切成尖椭圆 + 中央脉，朝向 = 枝方向 + 随机 + 向外，带「树冠椭球的法线」`crownN`。
  - **数据**：全部树的干 / 枝进一个 StructuredBuffer（48B 顶点）+ R32 索引，`DrawIndexed` 一次（无 input layout，SV_VertexID = 索引值）；叶子一个 StructuredBuffer（64B），`DrawInstanced(6, 叶数)`。每棵树一个 `State`（64B：根、高、梢的倾斜 / 速度、空气、windAmt、柔度、树冠中心、揺さぶり）。
  - **摇动 `TreeSwayCS`**（影子之前 1 次，每树 1 线程、子步 ≤ 8ms）：树冠处的空气 = 天气风（和草同一个波）+ 风源经 `WindGridBlend`（风格子）+ 突風的扇（和落ち葉同一批，`GroundDebris::PackGusts`）；目标倾斜 = 风速² × `leanPerWind2` × 柔度 × h（上限 `maxLean` × h）+ 乱流，按 `freq` × sqrt(5/h) 的弹簧追（高树慢）；爆炸（`kAreaShake` 的范围，不含胶囊）向外推并加 `shake`。VS 里干按 `mainW` 倾斜（带下沉），枝按 `branchW` 沿风 / 横向 / 上下摆，叶子绕尖端轴翻 + 顺风弯。
  - **绘制顺序**：干 / 枝在不透明段（Props 后、描边前，有アウトライン和 SSAO）；叶子在草 / 落ち葉之后（描边之后，每片叶不带线）；影子段两者都画（叶子用只做 discard 的 PS）。光照 = `ShadeLambert`（光源 CB 在 b1，`TreeCB` 占 b0），叶的法线 = 朝相机的叶法线和 `crownN` 按 `crownMix` 0.7 混合（整团像一个球受光），树冠里面按 `innerDark` 变暗。
  - **颜色**：第一版叶色 (0.20,0.42,0.10) 在亮草旁边发灰发暗 → 改成 `leafColor` (0.14,0.46,0.04) 〜 `leafColor2` (0.36,0.60,0.05)（每棵树随机插值）、`innerDark` 0.65、树皮 (0.36,0.25,0.16)。第一版树冠稀、干细高 → 干缩短、大枝加多放平、叶数约 ×3。
