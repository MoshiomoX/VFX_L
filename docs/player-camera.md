- **战斗相机**：`Camera/FollowCamera`，背后第三人称视角：
  - 鼠标：场景每帧调 `InputManager::RequestMouseCapture`（不调了下一帧自动放开），光标隐藏并锁在窗口中央 1px，Raw Input（WM_INPUT）的位移直接转视角，不用按键。捕获中给 ImGui 设 `NoMouse`。Alt 单按切换显示光标（松开时触发，中间按了别的键就不算，`InputManager::GetAltTap`），显示时游戏不暂停。UI 打开 / 死亡 / 调试相机时强制显示光标，这时不接受 Alt。`Window.cpp` 屏蔽了 `SC_KEYMENU`（否则单按 Alt 会让游戏循环卡住）
  - 平滑跟随用 SmoothDamp，水平、垂直分开调
  - 相机偏到右肩。默认距离 **14m、俯角 45 度**（2026-10-19 PokéBonk 风的地形时拉高拉远；之前 10m / 32 度，2026-10-05 用户要求「整体再往斜后方」，从 8m / 28 度调过来；2026-09-29 从 6m / 20 度拉远到 8m / 28 度：玩家反馈爆炸特效挡视线；同时把 `Explosion.json` / `MeteorBlast.json` 的闪光、火团、烟压了量和尺寸，烟的寿命 x0.65）
  - 遮挡处理：场景通过 `SetOcclusionProbe` 用 5 条射线打 `Layer_Terrain`。有东西挡住时相机立刻拉近，没挡住后慢慢退回原距离
  - 震动：调用 `AddTrauma`，抖动幅度 = trauma²。只作用在 `CameraBase::SetViewShake` → 视图矩阵上，不影响 `GetForward`，所以移动和朝向不会跟着抖
  - 触发：场景看玩家 HP 掉了多少（`OnPlayerHit`），以及「会震的范围」出现了几个（`OnShakeAreas`）。参数都在「Camera」面板。**2026-10-03 改（用户：特效拉满时画面一直震）**：以前是 GPU `aliveAreas` 每增加 1 个就**加** 0.12，命中火花（`VoidPop` 等 5 种 0 伤害范围）和死亡碎裂的土烟（`MobDeath`）也算，每秒十几个就超过衰减（1.4/秒），trauma 一直顶在 1（满幅 ±2.5° / 翻滚 ±4°）。现在：范围 json 的 `cameraShake`（F4 Area 页「Camera Shake」，`AreaProfile::cameraShake` → flags bit 3 `Swarm::kAreaShake` / `SWARM_AREA_SHAKE`）只有 Explosion / MeteorBlast / BomberBlast / Beam 开；`SwarmLiquidTrackCS` 发现新范围时对带这个标记的 `InterlockedAdd` 进 16B 的 `m_ShakeBuffer`（永久累加，3 张 staging 回读，`SwarmSystem::ConsumeShakeAreas` 取差分，没动 `SwarmCounters`）；两种触发都从「加」改成「至少抬到」（`FollowCamera::RaiseTrauma`），连续来也不超过上限；爆炸每个 0.12 → 0.25、上限 0.35 → 0.4（只数爆炸后单发太弱）。自测：`death`（5.5 秒 19 击杀）trauma 全程 0，`chain` 只有陨石落地时震。自测日志每行多了 `trauma`
  - **调参保存（2026-09-28）**：Camera 面板顶部 Save / Load / Reset to defaults → `Assets/Data/Camera.json`（`BattleCamera::SaveSettings/LoadSettings/ResetSettings`，Init 时自动读，没有文件就用代码默认值）。要保存的字段列在 `BattleCamera.cpp` 的 `CAMERA_FLOATS` / `CAMERA_BOOLS` / `CAMERA_TRIGGER_*` 宏表里，**FollowCamera 加参数时在表里加一行**。同时加的参数：`fov`（原来写死 45）、`defaultYaw/defaultPitch` + 「Reset view」「Use current as default」、**速度演出**（水平速度超过 `speedStart` 6 m/s 的部分：每 m/s 加 FOV 1 度（上限 +10）、拉远 0.12 m（上限 1.5），速度用目标位移 / dt 平滑得到；实测滑到 17 m/s 时 FOV 55、+1.33 m）、**前瞻** `lookAheadTime`（默认 0 = 关）、**滚轮调距离**（捕获鼠标时，`zoomMin..zoomMax`，改的是 `distance` 所以能保存）。顺带修了 `InputManager` 的滚轮：以前在 Update 里被清零、读不到，现在和鼠标位移一样先累计再在 Update 里取出。
- **滑铲（斜坡加速）**：按住左 Ctrl / 手柄 B（`InputMap::GetSlideHeld`；10-28 以前是手柄 X，X 现在是互动）。`PlayerControlSystem`：进入时（接地）平地也推到 moveSpeed × `slideBoost`（`slideBoostCooldown` 秒一次）；滑行中按脚下法线 `RigidbodyComponent::groundNormal`（`PhysicsSystem` 取最斜的地面接触）往下坡加速（水平 = `slideGravity` × cosθ sinθ，物理的重力投影也会再加一点），减 `slideFriction`，封顶 `slideMaxSpeed`，转向限 `slideTurnRate`；速度低于 `slideMinSpeed` 就站起，并且要松开再按才能再滑（`slideNeedsRelease`）；离地 0.2 秒内继续滑。跳起 / 松开后多出 moveSpeed 的惯性（`carryMomentum`）按 `momentumDecay`（空中 `momentumDecayAir`）减；普通跑步照旧每帧设成输入 × moveSpeed。滑行中朝向 = 速度方向。状态 `MoveStateID::Slide`（`PlayerStateComponent::slideActive`），动画 `Slide_Loop`（UAL2 的脚在前滑垒姿势，见「玩家模型」）；`SkinnedAnimComponent::leanDeg` 以脚底为轴后仰（`PlayerAnimSystem::slideLeanDeg`，RenderSystem 里在 offset 之前转）现在默认 0（KayKit Mage 用 `Crouching` 时是 15）。参数全在 `PlayerStatsComponent`，战斗场景 Player 面板「Slide」可调并显示速度 / 脚下坡度。坡道（28 度约 5〜7m）很短，实测 26 度 7m 的坡从 8 滑到 13.4 m/s；高台的长坡（seed 12345，19 度、斜着滑 25m）从 8 滑到约 18 m/s，正对坡滑 19m 到 19.7 m/s。**2026-10-09 用户「滑铲冲刺之后的速度衰减慢一点」**：`slideFriction` 5 → 3 m/s²、`momentumDecay`（滑完后多出的惯性，地上）6 → 3.5 m/s²；`slide` 自测平地段实测 7.97 → 3.28 m/s 用了 1.6 秒（原来约 1 秒）。
