- **飛ぶ Boss の高さは本当の位置（2026-11-01，用户：「石头兽飞的时候，魔法的击中点是它身体下方，不是它正在飞的位置」）**：以前 `bossHover` 只抬画面和血条，真实位置贴地，瞄准、命中、伤害数字都在脚下。现在 `SwarmBodyHover`（石像鬼 + `g_BossHover`）由 `SwarmEnemyMoveCS` 写进 `position.y`，和石像鬼同样的做法；`SwarmEnemyVS` 只留上下浮动，血条不再单独加高度；圆影和死亡碎片用减掉高度后的地面位置。`CollisionTestSceneBoss.cpp` 里 `bossFly = fly || hover > 0.01`：降落途中还算飞行，否则一切到 Settle 就直接摔下去。这几招的判定都是 CPU 按水平距离算的，不受高度影响。影响到的 Boss：石の守護獣、砂嵐の魔神、骸の王。自测 `VFXL_BATTLE_AUTOTEST=flyhit`（`Debug/AutoTest/AutoTestFlyHit.cpp`，**要 `git add -f`**；Boss 要写 `flyhit:s3:bbeast`，`RunTests.ps1` 会清掉 `VFXL_BOSS_TYPE`）。11-01 实测：石の守護獣位置离地 3.50m（0.9 + 2.6），火球 8 秒打掉 200 血；魔神 2.10m / 160。`bossmoves:s3:bbeast` 和 `:s2:bdjinn` 全部招式回归通过；`dive-side` 挪到 `dive` 之后（放在 `crush` 后面时，Boss 被带到别处，玩家横闪的路线不同，是测试场地的问题，改回旧高度对照过）。`charge-beast` 0 次命中也是这个原因（Boss 撞遗迹房间的墙，10-29 就记过）。**没验证**：天からの圧殺升到 16m 时的瞄准、骸の王没单独跑。**11-09 修（用户：「飞行敌人时陨石这类的脚下预警圈在天上」）**：落点以前取敌人的实际位置（含飞行高度）→ 陨石 / 毒瓶的预警圈、爆炸、毒沼都出在空中。现在 `SwarmSpawnProjCS`（新绑 BomberCB b3）对 Drop / Lob 的落点减 `SwarmBodyHover` = 落在飞行敌人正下方的地面；同时 `SwarmAreaDamageCS` 对非胶囊的范围多判一次「敌人在地面的投影」的竖直距离（`abs(d.y - hover)`），否则地面的爆炸够不着空中的身体。`flyhit` 多了 `VFXL_FLYHIT_ITEM=meteor|poison`（铺满框、放那个魔法），11-09 石の守護獣（离地 3.5m）：陨石每发 −50、毒沼持续掉血，截图里预警圈 / 毒沼在 Boss 脚下的地面。光线（胶囊）照旧只按身体高度判。
